# AdorePark — UI Design System Specification
**Society**: Adore Grand, Sector 85, Faridabad, Haryana, India  
**Visual Identity**: Bright, Friendly, Premium Residential Community (Light Mode Only)

---

## 1. Design System Philosophy

AdorePark's visual identity is designed specifically for **Adore Grand, Sector 85, Faridabad**. The interface eschews dark cyberpunk or generic SaaS templates in favor of a **bright, welcoming, friendly consumer aesthetic**:
- **Approachable for 60+ Senior Residents**: Large touch targets (`52px`–`56px`), high typography contrast, and bilingual Hindi/English guidance.
- **Modern for Young Residents**: Soft rounded cards, smooth Framer Motion micro-interactions, clean vector cartoon illustrations.

## 3. Component Design Tokens

### 3.1 Cards & Containers
- **Border Radius**: `rounded-3xl` (`1.5rem` / `24px`)
- **Borders**: `1px solid #e2e8f0`
- **Shadows**: `box-shadow: 0 10px 25px -5px rgba(15, 23, 42, 0.05)`

### 3.2 Typography
- **Major Display Headings**: `Outfit` (Weight: `700`–`900`)
- **Body & Controls**: `Plus Jakarta Sans` (Weight: `500`–`800`)

### 3.3 Touch Targets & Buttons
- **Primary Buttons**: `52px`–`56px` height, `rounded-2xl`, fresh emerald green (`#059669`) with white text.
- **Emergency Buttons**: Soft coral (`#e11d48`) with white text.
- **Rounded Icon Containers**: `14x14` icon pills (`rounded-2xl`) with soft pastel background tints.
